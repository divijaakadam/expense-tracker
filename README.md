# 💰 Personal Expense Tracker (Python & Flask)

A simple and user-friendly personal expense tracking web application built primarily with **Python and Flask**.

Users can add, edit, delete, search and filter expenses, view spending statistics, set a monthly budget, export expenses to CSV, and switch between light and dark mode.

> **Note:** This version does not use a database. Expense data is stored temporarily while the Flask application is running.

## ✨ Features

- Add expenses
- Edit expenses
- Delete expenses
- Search and filter expenses
- View expense statistics and chart
- Set a monthly budget
- Export expenses to CSV
- Light and dark mode
- Responsive interface

## 🛠️ Technologies Used

- **Python** – Main programming language
- **Flask** – Python web framework
- **HTML** – Website structure
- **CSS** – Website styling
- **JavaScript** – Frontend interactions
- **Chart.js** – Expense chart
